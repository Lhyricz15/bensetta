BENJAMIN & ROSETTA — OUR LITTLE FOREVER
========================================

PACKAGE CONTENTS
- index.html: complete responsive anniversary website. No external libraries or build tools are required.

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Double-click index.html to open it in a modern browser.

PUBLISH WITH GITHUB + VERCEL
1. Sign in to GitHub and create a new repository (for example: benjamin-rosetta-anniversary).
2. Upload index.html to the repository's root folder.
3. In Vercel, choose Add New -> Project and import that GitHub repository.
4. Keep the default settings for a static HTML site and click Deploy.
5. When deployment completes, open the Vercel URL and test it on your phone.

IMPORTANT NOTES
- The website uses a responsive layout and does not require a build step.
- The secret message unlock key is 27102023 (27 October 2023).
- Memory file selection is a local browser preview only. It does not upload files or share them with another person/device. Shared uploads require a connected backend/storage service.
- This version contains no personal photos because no photo files were included in the rebuild. You can add photos through the Memories section for a local preview, or later place image files in the site and update the HTML to include them.
- All anniversary wording is editable in index.html using a text editor.
